# Vehicle Rental Management System

## Project Description
A full-stack web application that allows users to search for rental vehicles, view prices, book vehicles, and manage booking history.

## Features
- View available vehicles and rental prices.
- Search vehicles by location.
- Book vehicles using pickup and return dates.
- Calculate rental costs automatically.
- Validate booking dates.
- Prevent overlapping bookings for the same vehicle.
- View booking history.

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: SQLite
- Version Control: Git and GitHub
- Code Editor: Visual Studio Code

## Installation
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Install dependencies using `npm install`.
4. Start the application using the start command configured in `package.json`.
5. Open `http://localhost:3000` in your browser.

## Objective
To develop a simple vehicle rental platform that manages vehicle searches, bookings, pricing, and booking records.
## Booking Validation
The system validates pickup and return dates, calculates the total rental cost, and prevents overlapping bookings for the same vehicle.

The system validates pickup and return dates, calculates the total rental cost based on the rental duration, and prevents overlapping bookings for the same vehicle.
